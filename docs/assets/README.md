# Скриншоты проекта

Для портфолио замените SVG-заглушки PNG-снимками реального интерфейса после запуска и `seed-demo`:

- `dashboard-placeholder.svg` → снимок дашборда с прогнозом и доходностью;
- `contracts-placeholder.svg` → снимок договоров и ledger;
- `roi-placeholder.svg` → снимок доходов, расходов и ROI объекта.

Снимки следует сделать в браузере на демо-данных и без личных сведений.
