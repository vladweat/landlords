# Визуальные материалы

В текущем README и портфолио используются SVG-заглушки, а не реальные снимки
интерфейса. Для публикации замените их PNG или WebP captures после запуска и
`seed-demo`:

- `dashboard-placeholder.svg` → снимок дашборда с прогнозом и доходностью;
- `contracts-placeholder.svg` → снимок договоров и ledger;
- `roi-placeholder.svg` → снимок доходов, расходов и ROI объекта.

Снимки следует сделать в браузере на демо-данных и без личных сведений. После
замены обновите ссылки в [`README.md`](../../README.md) и
[`PORTFOLIO.md`](../PORTFOLIO.md); не переименовывайте заглушки так, будто они
содержат настоящие captures.
