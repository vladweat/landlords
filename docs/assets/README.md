# Визуальные материалы

В каталоге находятся SVG-заглушки для иллюстраций интерфейса. Файлы можно
заменить PNG или WebP изображениями соответствующих разделов приложения:

- `dashboard-placeholder.svg` → снимок дашборда с прогнозом и доходностью;
- `contracts-placeholder.svg` → снимок договоров и ledger;
- `roi-placeholder.svg` → снимок доходов, расходов и ROI объекта.

Изображения должны соответствовать текущему интерфейсу приложения.
