# Архив продуктового roadmap

Этот документ сохраняет планирование и решения сентября–октября 2026. Его
checkbox и формулировки «следующий шаг» — исторический контекст, не текущий
backlog. Текущее поведение см. в [справке по продукту](index.md).

Ядро CRM уже есть: договоры, ledger, роли, PDF, Celery, дашборд. До «настоящего продукта» не хватает не фич, а того, без чего им нельзя пользоваться каждый день и за что нельзя брать деньги.

Операционный порядок работ — [priorities.md](./priorities.md).
Инфра и деплой: [infra.md](./infra.md).
Код без переписывания архитектуры: [backend/architecture.md](../backend/architecture.md).

## Порядок работ

Чеклист = [priorities.md](./priorities.md). Отмечай `- [ ]` → `- [x]`.

### 1. Чтобы это можно было задеплоить

- [x] Docker: online (`pip install`) и offline (`COPY .venv`); миграции при старте; healthcheck `/ready`
- [x] Один вход: nginx → API + статика; без конфликта порта 80
- [x] Секреты только из env; заполнен `.env.example`
- [x] Полный CI: ruff → unit → integration → `tsc`/build → online image
- [x] Зелёный frontend `tsc` / `npm run build`
- [x] Бэкап Postgres + `storage/documents`, runbook в [deploy.md](./deploy.md)
- [x] Root README + демо-аккаунт (`app.cli seed`)

После этого — VPS и пользование самому.

### 2. Чтобы чужой человек мог работать каждый день

- [x] Реальная почта (SMTP): регистрация, сброс пароля, напоминания о просрочке и конце договора
- [x] Invite по ссылке (owner / manager / accountant без ручной выдачи пароля)
- [x] Публичная страница арендатора (**#12**): баланс, инвойс, «я оплатил» по magic link
- [x] Аудит в UI: contract events уже пишутся — показать owner
- [x] Массовые действия: начисления / экспорт по нескольким договорам
- [x] UX-долг: Error Boundary; убрать мёртвый `ForecastWidget` и лишний `antd`

Импорт банковской выписки (**#11**) — после почты и #12.

### 3. Чтобы это был SaaS, а не личный инструмент

- [x] Тарифы и лимиты: объекты, пользователи, хранилище (plans/subscription)
- [x] Оплата: ЮKassa (test/demo), webhooks, отключение при неоплате (Pro; Enterprise вручную)
- [x] Юридическое: оферта, политика данных, удаление аккаунта, выгрузка
- [x] Наблюдаемость: Sentry + алерты на beat и диск документов
- [x] Поддержка: почта «написать нам», статус инцидентов

### 4. Что не делать сейчас

- [ ] Мультивалюта / индексация аренды (**#14**)
- [ ] Заявки на ремонт (**#13**)
- [ ] Google Calendar / 1С / мобильное приложение (**#15**; Telegram как канал напоминаний — ок после SMTP)

Не двигают «можно пользоваться».

## Критерий «готово»

1. Ты и второй человек заводите объекты и договоры на публичном URL.
2. Начисление создаётся по расписанию, просрочка уходит на почту, PDF открывается по ссылке.
3. Менеджер входит по приглашению и не видит чужой аккаунт.
4. `git push` не проходит, если красные тесты или `tsc`.
5. Бэкап восстанавливается. Пароль сбрасывается письмом, не файлом на диске.

Для демонстрации продукта полезны живой стенд, настроенная почта и CI.
